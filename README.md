Solmere Heat — an original open-world crime game in the spirit of GTA 6, built with three.js. Drive and walk through the sun-soaked coastal city of Solmere: steal cars, dodge the police across a five-star wanted scale, run a fifteen-chapter story as wheelman Danny Reyes, and fight with eight weapons — including the SV-9 Deadeye sniper, a one-shot scoped rifle, the Kestrel DMR marksman rifle, the Tempest LMG, and the Whisper X9, a silent scoped crossbow that raises no heat. Nine vehicle types (sedan, coupe, SUV, pickup, muscle car, van, motorcycle, taxi cab, police cruiser), twelve hidden Sun Coins to collect, three street races with best times, taxi fares with streak bonuses, three buyable properties that pay passive income, a full day-night cycle with lamps, moonlight and quieter nights, a lighthouse with a rotating beacon, traffic, pedestrians, a live minimap, synthesized sound and local saves included. Everything is procedural; the game plays offline in a desktop browser with no network requests.

## Run it

```sh
node serve.ts
```
Then open http://localhost:8080 — or serve game/ with any static HTTP server.

## Controls

WASD move / drive · mouse look (click to lock) · E enter / exit car · Shift sprint · Space jump / handbrake · left mouse fire · F punch · R reload · 1–8 / wheel switch weapons · hold right mouse to scope the sniper, DMR or crossbow · M mute · Esc pause · J start the next story chapter · drive into a checkered start ring to race · T pick up a taxi passenger · B buy the property you stand by.
