Solmere Heat — an original open-world crime game in the spirit of GTA 6, built with three.js. Drive and walk through the sun-soaked coastal city of Solmere: steal cars, dodge the police across a five-star wanted scale, run a twelve-chapter story as wheelman Danny Reyes, and fight with seven weapons — including the SV-9 Deadeye sniper, a one-shot scoped rifle, the Kestrel DMR marksman rifle, and the Tempest LMG. Eight vehicle types (sedan, coupe, SUV, pickup, muscle car, van, motorcycle, police cruiser), twelve hidden Sun Coins to collect, three street races with best times, a lighthouse with a rotating beacon, traffic, pedestrians, a live minimap, synthesized sound and local saves included. Everything is procedural; the game plays offline in a desktop browser with no network requests.

## Run it

```sh
node serve.ts
```
Then open http://localhost:8080 — or serve game/ with any static HTTP server.

## Controls

WASD move / drive · mouse look (click to lock) · E enter / exit car · Shift sprint · Space jump / handbrake · left mouse fire · F punch · R reload · 1–7 / wheel switch weapons · hold right mouse to scope the sniper or DMR · M mute · Esc pause · J start the next story chapter · drive into a checkered start ring to race.
